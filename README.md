Objective:
Collaboration with Alstom to promote VR/AR and AI in Bourgogne-Franche-Comté, creating public-private partnerships and fostering innovation.


My contribution:
Development of the AI to classify 3D pieces, using methods such as standardization, PCA, DBSCAN, K-means, and affinity propagation from scikit-learn.


Process:
Conception and implementation of a Proof of Concept (POC) within two weeks: finding the nearest neighbor of a 3D piece, predicting future prices, and facilitating Alstom's decision-making.

Team:
- 1 undergraduate student in Computer Science (Year 1): Designing the showcase page presenting our project.
- 2 undergraduate students in Computer Science (Year 3): Establishing a database and user interface.
- 3 graduate students in Computer Engineering, including myself (Year 4): Coordinating and managing the overall project, as well as proposing an AI solution.

Outcome:
The result of this project is a website with a functional administration interface. This platform enables users to:

- Import and visualize a 3D file in .stp format.
- Locate the most similar piece, accompanied by an accurate resemblance rate.
- Obtain price forecasts for both pieces, simplifying the decision-making process for Alstom buyers.
